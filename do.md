Refactor the website typography system to improve modern design quality and accessibility for a school website.

## Font System Requirements

Use Google Fonts only and choose ONE of the following approved modern accessible font systems:

### Option A (Recommended – Balanced & Modern)

* Headings: Plus Jakarta Sans
* Body: Inter

### Option B (More Premium / Tech-forward)

* Headings: Manrope
* Body: Inter

### Option C (Friendly / Education-focused)

* Headings: Outfit
* Body: Inter

### Accessibility-focused option (highest readability)

* Headings: Source Sans 3
* Body: Inter or Source Sans 3

👉 Choose the best option based on existing UI style, but keep consistency across the entire site.

---

## Accessibility Requirements (Mandatory)

* Must meet WCAG AA contrast and readability standards
* Minimum body font size: 16px
* Line height: 1.5–1.7 for paragraphs
* Avoid thin font weights (<400) for body text
* Ensure clear hierarchy between headings and body text
* Ensure readability on mobile devices without zooming

---

## Design Goals

* Create a modern, premium educational institution look
* Improve visual hierarchy using typography (not color overload)
* Make headings more expressive and structured
* Keep body text highly readable for long reading sessions
* Maintain consistent spacing and rhythm across pages
